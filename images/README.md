# Mahsulot rasmlari

Mahsulot rasmlarini admin paneldan (`/admin`) yuklash qulayroq: ular
`data/uploads/` papkasiga saqlanadi. Bu papka esa bosh sahifa rasmlari va
qo'lda qo'yiladigan rasmlar uchun.

- Formatlar: `.jpg`, `.jpeg`, `.png`, `.webp`
- Nomda faqat lotin harflari, raqamlar, `-` va `_` bo'lsin (bo'sh joysiz).
- Rasm topilmasa, kartochkada rangli fon ko'rinadi.

## Bosh sahifa rasmlari

Bosh sahifadagi uchta katta blok uchun:

- `hero-1.jpg` — chapdagi baland blok (tik rasm, taxminan 3:4)
- `hero-2.jpg` — o'ng tepadagi kvadrat blok
- `hero-3.jpg` — o'ng pastdagi kvadrat blok

Faqat o'zingizga tegishli yoki ishlatishga ruxsat berilgan rasmlarni qo'ying.
